# 🎬 Streamflix

A fully responsive streaming platform interface inspired by modern services like Netflix. This project was built to showcase front-end development skills using HTML, CSS, and JavaScript.

## 🚀 Features

* 👤 Profile selection screen
* 🎥 Movie/series catalog interface
* 🖼️ Full HD images and banners
* 🖱️ Hover interactions and animations
* 📱 Fully responsive design

## 🛠️ Technologies Used

* HTML5
* CSS3 (Flexbox & Grid)
* JavaScript
